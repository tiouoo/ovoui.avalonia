# OvoUi.AvaloniaEdit

OvoUi integration for AvaloniaEdit, including the `CodeBlock` control and syntax highlighting support.

Add the theme to the application after `OvoUiTheme`:

```xml
<Application.Styles>
    <ovo:OvoUiTheme />
    <ovo:OvoAvaloniaEditTheme />
</Application.Styles>
```

The optional preview-and-source control is distributed separately in `OvoUi.AvaloniaEdit.Showcase`.
